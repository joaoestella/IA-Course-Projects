# 🤖 Artificial Intelligence - Course Projects

This repository is a collection of assignments and technical checkpoints developed during the Artificial Intelligence course (2025). It demonstrates the application of machine learning algorithms to solve diverse problems, ranging from basic classification to real-world data regression and clustering.

## 📂 Project Structure

The projects are organized within the `assignments/` directory for better maintainability:

### 📍 [CP1] Classification: KNN & Decision Trees
*   **Description:** Implementation and comparison of two supervised learning models.
*   **Focus:** Distance-based classification (K-Nearest Neighbors) and logic-based classification (Decision Trees).
*   **Tools:** Python, Scikit-Learn.

### 📍 [CP2] Hyperparameter Optimization
*   **Description:** Techniques to refine model performance and prevent overfitting.
*   **Focus:** Using tools like GridSearchCV or RandomizedSearchCV to find the best model configuration.

### 📍 [CP4] Regression: NYC Taxi Trip Duration
*   **Description:** Predictive analysis using a real-world dataset of taxi trips in New York City.
*   **Focus:** Exploratory Data Analysis (EDA), handling geospatial data, and time-series feature engineering.

### 📍 [CP5] Clustering: Unsupervised Learning
*   **Description:** Identifying patterns and grouping data without predefined labels.
*   **Focus:** Implementation of clustering algorithms (e.g., K-Means) and performance evaluation using metrics like the Elbow Method.

## 🛠️ Tech Stack

*   **Language:** Python
*   **Environment:** Google Colab
*   **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib/Seaborn

Most projects include an **"Open in Colab"** button at the top of the notebook. Clicking it will allow you to run the code directly in your browser without any local setup.
